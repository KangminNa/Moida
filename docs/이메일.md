# 알림 메일 (플러그인 `email`)

콘솔의 알림(승인 요청 · 작업 실패 · 자동화 멈춤 …)을 관리자의 메일로도 보낸다 (2026-11-26, 기획서 결정 기록).
코어는 메일을 모른다: 알림이 푸시로 보내기로 정한 것마다 `platform.notice.sent`를 남기고, 플러그인이 받아 한 통씩 보낸다.

## 언제 · 무엇이 가나

- 푸시와 같은 때 · 같은 묶음이다. 콘솔 › 설정 › 알림의 조용한 시간 · 묶음 간격 · 종류마다의 경로를 그대로 따른다.
  경로가 "알림 센터만" · "끄기"인 종류는 메일도 가지 않는다. 즉시 알림이 네 개 넘게 쌓이면 "알림 n개" 한 통으로 묶인다.
- 브라우저 푸시를 켜지 않아도 메일은 간다.
- 메일에는 제목과 콘솔 링크만 싣는다. 메일은 메일 회사를 거치므로 대화의 답 같은 내용은 "알림 본문도 싣기"를 켤 때만 싣는다.
- 승인 단추는 없다. 승인은 늘 콘솔에서 한다 (원칙 7).
- 보내다 실패하면 일꾼이 다시 시도한다 (8번 실패하면 설정 › 일 › 처리 실패에 보인다). 메일 서버가 받았는데 답을 놓치면 같은 메일이 두 번 갈 수 있다.

## 메일 서버

메일 서버를 직접 띄우지 않는다. 가정용 회선은 25번 포트가 막혀 있고, 집 IP와 DuckDNS 도메인으로는 PTR · SPF · DKIM을 맞출 수 없어
보낸 메일이 닿지 않는다. 메일 회사의 SMTP에 로그인해 보낸다. 465 포트(TLS로 바로 붙기)만 쓴다.

### Gmail로 설정하기

1. Google 계정 › 보안에서 2단계 인증을 켠다.
2. 같은 곳의 "앱 비밀번호"에서 하나 만든다 (16자리). 계정 비밀번호는 넣지 않는다.
3. 콘솔 › 설정 › 플러그인 › 알림 메일(`email`)을 켜고 칸을 채운다.

| 칸 | 값 |
|---|---|
| SMTP 서버 · 포트 | `smtp.gmail.com` · `465` (기본값) |
| 보내는 계정 | Gmail 주소 |
| 앱 비밀번호 | 2에서 만든 16자리 (비밀 칸, 서버 키로 암호화) |
| 받을 주소 | 비우면 보내는 계정으로 |
| 이 Cairn의 바깥 주소 | `https://…` (메일 안 링크의 앞부분) |

4. "테스트 메일 보내기"를 누른다. 명령줄은 `pnpm plugin email test`.
   로그인 거절(535)이면 앱 비밀번호를 다시 만든다. 오지 않으면 스팸함을 본다.

Gmail은 하루 약 500통까지 보낸다. 관리자 알림에는 충분하다.
배포 서버에서 `smtp.gmail.com:465`로 나가는 연결이 열려 있어야 한다.

## 코드

- `plugins/email/server/smtp.gateway.ts`: 라이브러리 없이 `node:tls`로 SMTP (EHLO · AUTH PLAIN · MAIL · RCPT · DATA · QUIT). 인증서는 Node의 기본 검사.
  587(STARTTLS)은 쓰지 않는다. 오류 글에는 메일 서버의 번호와 글만, 비밀번호는 싣지 않는다
- `mail-message.ts`: 메일 한 통. 제목은 UTF-8 encoded-word, 본문은 base64. 주소는 모양을 보고 제목은 한 줄로 만들어 머리글을 끼워 넣지 못한다
- `notice-mail.ts`: 알림 메일의 내용. 링크는 이 Cairn 안의 경로만
- `notice-sent.handler.ts`: `platform.notice.sent` 하나에 메일 한 통 (일꾼, 트랜잭션 밖)
- 테스트: `email.test.ts`가 127.0.0.1의 테스트용 SMTP 서버(`fake-smtp.ts`, TLS 없이)로 주고받기 · 로그인 거절 · 받는 사람 거절을 본다.
  코어 쪽은 `push.api.test.ts`가 보내기로 정한 알림마다 이벤트가 한 번 남는지 본다

## 다음 단계 (아직 만들지 않음)

구독자에게 보내는 소식 메일: 방문자가 앱에서 주소를 넣고(두 번 확인), 새 글이 공개되면 발송 초안 → 승인 → 천천히 보내기, 모든 메일에 해지 링크.
여럿에게 보내는 메일은 자기 도메인과 발송 회사(SPF · DKIM)가 필요하고, 발송마다 승인(원칙 7) · 해지한 주소 지우기(원칙 2 예외)를 정해야 한다.
